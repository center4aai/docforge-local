# External Reference Materials (legacy `methodology/` path)

Place optional external/domain-background reference materials for the project here.

## Intended use

These files are optional external context for DocForge Local.

They may include:
- scientific papers;
- internal specifications;
- architecture notes;
- methodological descriptions;
- domain terminology references.

## Important rule

These files do **not** override code facts automatically.

They should influence:
- terminology;
- intended architecture explanations;
- routed reference-alignment sections;
- mismatch reporting between intended design and actual implementation.

They should **not** silently replace:
- module names;
- function signatures;
- actual dependency structure;
- real runtime behavior.

## Suggested future subfolders

- `papers/`
- `specs/`
- `notes/`
- `glossary/`
